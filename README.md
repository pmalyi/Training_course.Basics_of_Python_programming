### Початок роботи

1.  **Встановіть Python** з офіційного сайту [python.org](https://www.python.org/downloads/).

2.  **Оберіть редактор коду.** Рекомендуємо [Visual Studio Code](https://code.visualstudio.com/) з розширенням для Python або [PyCharm Community Edition](https://www.jetbrains.com/pycharm/download/).

3.  **Проходьте розділи послідовно**, починаючи з першого.
    *   Прочитайте теорію.
    *   Виконайте практичні завдання.
