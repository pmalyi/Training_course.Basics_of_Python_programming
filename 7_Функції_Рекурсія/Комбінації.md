Умова  
---
Дано два цілі числа $n$ та $k$ з діапазону від 1 до 10 ($k$ $<$ $n$ ).

Знайти всі **зростаючі послідовності** довжиною $k$, що складаються з чисел від $0$ до $n-1$.

Усі такі $k$-послідовності виведіть на екран, кожну в окремому рядку. Окремі $k$-послідовності можуть бути виведені в 
довільному порядку.

---

### Приклад Введення/Виведення

| Вхід (Input) |                                                           Вихід (Output)                                                           | Пояснення |
| :---: |:----------------------------------------------------------------------------------------------------------------------------------:| :--- |
| `5 3` |`0 1 2`<br/>`0 1 3`<br/>`0 1 4`<br/>`0 2 3`<br/>`0 2 4`<br/>`0 3 4`<br/>`1 2 3`<br/>`1 2 4`<br/>`1 3 4`<br/>`2 3 4`<br/> (10 рядків) | Комбінації $\binom{5}{3}$ |
| `8 8` |                                                    `0 1 2 3 4 5 6 7` (1 рядок)                                                     | Комбінація $\binom{8}{8}$ |

**Суть завдання:** Згенерувати всі **комбінації без повторень** довжиною $k$ з набору $\{0, 1, \dots, n-1\}$.

Комбінаторний Термін
---
**Комбінація без повторень** — це вибір $k$ елементів із заданої множини $S$, що містить $n$ **різних** елементів, де:

1.  **Порядок елементів не має значення** (тобто, множина $\{a, b\}$ вважається такою ж, як $\{b, a\}$).
2.  **Елементи не повторюються** (кожен елемент із множини $S$ може бути вибраний лише один раз).

### Формальне Означення

Нехай $S$ — це скінченна множина з потужністю $|S| = n$.
**Комбінація без повторень** довжини $k$ (або $k$-комбінація) — це будь-яка **підмножина** множини $S$ з потужністю $k$.

$$\text{Комбінація} = A \subseteq S, \quad \text{де } |A| = k$$

---

  * **Назва:** **Комбінації** (Combinations).
  * **Позначення:** $\binom{n}{k}$ або $C(n, k)$.
  * **Формула:** Кількість таких послідовностей (або наборів) дорівнює:
    $$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

Розглянемо приклад $n=5$ (числа від 0 до 4, тобто 5 різних чисел) і $k=3$.
$$\binom{5}{3} = \frac{5!}{3!(5-3)!} = \frac{120}{6 \cdot 2} = 10$$
Як бачимо, отримаємо рівно 10 послідовностей.



## Математичний Опис Рекурсивної Функції

Нехай функція $\text{G}(i)$ представляє операцію генерації елементів, починаючи з позиції $i$ масиву $a$.

### 1. Предмет Обчислення

Функція $\text{G}(0)$ генерує множину $\mathcal{S}$ всіх можливих зростаючих послідовностей $a = (a_0, a_1, \dots, a_{k-1})$ таких, що:

1.  $a_i \in \{0, 1, \dots, n-1\}$ для всіх $0 \le i < k$.
2.  $0 \le a_0 < a_1 < \dots < a_{k-1} < n$.

### 2. Рекурсивне Визначення

Функція $\text{G}(i)$ виконує такі кроки:

#### А. Базовий Випадок

Якщо $i = k$:
$$\text{G}(k) \implies \text{Вивести послідовність } (a_0, a_1, \dots, a_{k-1})$$

#### Б. Рекурсивний Крок (для $i < k$)

1.  **Визначення Нижньої Межі (Start Value):**
    Нижня межа $\text{StartVal}(i)$ для поточного елемента $a_i$ залежить від попереднього елемента:
    $$\text{StartVal}(i) = \begin{cases}
    0 & \text{якщо } i = 0 \\
    a_{i-1} + 1 & \text{якщо } i > 0
    \end{cases}$$

2.  **Діапазон Значень:**
    Елемент $a_i$ перебирає значення $x$ у діапазоні $[\text{StartVal}(i), n-1]$, з додатковою умовою, що **залишиться достатньо елементів** для заповнення решти послідовності.

    $$\text{StartVal}(i) \le x \le n - (k - i)$$
    *(Умова $x \le n - (k - i)$ гарантує, що залишиться $k-i-1$ унікальних чисел, більших за $x$, щоб завершити послідовність. Це $n - 1 - x \ge k - i - 1$)*

3.  **Рекурсивний Виклик:**
    Для кожного допустимого значення $x$:
    $$\forall x \in [\text{StartVal}(i), n - (k - i)]$$
    Виконується:
    а. Встановлення: $a_i \leftarrow x$
    б. Рекурсія: $\text{G}(i+1)$

### 3. Зауваження

* **Тип обчислення:** Ця функція реалізує **пошук у глибину (DFS)** у дереві рішень для простору комбінацій.
* **Складність:** Оскільки вона генерує $\binom{n}{k}$ комбінацій, її часова складність є $O(\binom{n}{k} \cdot k)$, де $k$ — час, необхідний для виведення послідовності.

Усе це — елегантний спосіб сказати: "ми вибираємо наступне число, щоб воно було більшим за попереднє, і щоб нам вистачило чисел до кінця".

## Рекурсивне Рішення (Схема Програми)

Зазвичай такі задачі розв'язуються за допомогою **рекурсії з поверненням** (backtracking), оскільки діапазон $n$ та $k$ малий.

Ключова ідея: Коли ви вибираєте наступне число для зростаючої послідовності, ви можете обирати лише числа, більші за попереднє.

Ця рекурсивна функція генерує **комбінації без повторень** довжини $k$ з множини $\{0, 1, \dots, n-1\}$.

Оскільки вона не приймає явного параметра для нижньої межі, її математичний опис базується на **стані масиву $a$** на попередньому кроці.

---
```python
def generate_combinations(n: int, k: int):
    """
    Генерує та виводить усі зростаючі послідовності (комбінації без повторень)
    довжиною k з чисел {0, 1, ..., n-1}.
    
    :param n: Розмір набору (числа від 0 до n-1).
    :param k: Бажана довжина послідовності.
    """
    
    if k < 0 or k > n:
        print("Помилка: Необхідно 0 <= k <= n.")
        return

    # Послідовність, яку ми будуємо
    combination = [0] * k 

    def backtrack(index: int, start_value: int):
        """
        Рекурсивна функція для пошуку комбінацій.
        
        :param index: Поточна позиція (індекс) у послідовності (від 0 до k-1).
        :param start_value: Найменше можливе число для поточної позиції.
        """
        
        # Базовий випадок: Послідовність заповнена
        if index == k:
            # Виведення послідовності
            print(*(combination))
            return
            
        # Обмеження для ефективності: 
        # Якщо залишилося менше елементів (n - i) для вибору, 
        # ніж потрібно позицій (k - index), то завершуємо цикл.
        # i - це значення, яке ми намагаємося розмістити.
        
        # Фактичний верхній ліміт для циклу: 
        # x_max = n - (кількість елементів, які ще потрібно вибрати)
        # x_max = n - (k - index - 1) - 1
        
        end_limit = n - (k - index)

        # Перебираємо можливі значення x для поточної позиції index
        for x in range(start_value, end_limit + 1):
            
            # 1. Вибір: Встановлюємо значення
            combination[index] = x
            
            # 2. Рекурсія: Переходимо до наступної позиції.
            # Наступне число має бути принаймні x + 1 (строго зростаюча послідовність).
            backtrack(index + 1, x + 1)
            
            # Повернення: Не потрібно явно "відкочувати" стан (pop) у цьому стилі 
            # (де використовується фіксований масив), оскільки значення буде перезаписано.

    # Початковий виклик: Починаємо з 0-ї позиції, найменше значення - 0.
    backtrack(0, 0)


# Приклад використання (Ваш вхід: 5 3)
if __name__ == "__main__":
    N, K = map(int, input().split())
    print(f"Генерація комбінацій C({N}, {K}):")
    generate_combinations(N, K)
```
